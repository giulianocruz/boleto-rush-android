# Prompts de imagens para Google Flow — Boleto Rush! Premium

**Como usar:** abra o projeto Flow, adicione a imagem de referência oficial do mascote quando aplicável, cole o prompt do item isoladamente e configure a proporção informada. Não misture vários prompts numa única geração. Salve com o nome exato.

**Importante:** a direção é 2.5D estilizada, não 3D fotográfica. O texto de botões, números e títulos deve ser feito no Android/compositor para garantir ortografia e acessibilidade. Prompts em inglês para direção visual mais objetiva.
